How to Install

1
Download when the build is released Select Download StoneForge to request the free Windows installer. No game purchase, activation key, or account is needed to download.
2
Run StoneForgeSetup.exe Follow the installer instructions. The version and final download size will be published with the tested release.
3
Start your adventure Tutorial, Story Mode, and Multiplayer will share the same app. Online features require internet and a valid StoneForge account verified through your browser.

Your Account and Forge Medals

StoneForge no longer requires a one-time game purchase. Use the same account on the website and in the game for your Forge Medal balance, character unlocks, and perk upgrades.

Forge Medal purchases are optional and currently use sandbox checkout. No real money is charged. Existing account and transaction records are preserved.
